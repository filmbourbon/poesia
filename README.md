# De nada em nada, tudo.

Site do documentário. www.poesia.art.br

## Como publicar (passo a passo)

1. Descompacte o arquivo ZIP no seu computador.
2. Abra a pasta. Você vai ver: `index.html`, a pasta `assets`, a pasta `tests` e outros arquivos.
3. No navegador, entre em: github.com/filmbourbon/poesia
4. Clique no botão **Add file**.
5. Clique em **Upload files**.
6. Selecione TUDO o que está dentro da pasta (inclusive as pastas `assets` e `tests`).
7. Arraste tudo para a área de upload do GitHub.
8. Espere a lista de arquivos terminar de carregar.
9. Lá embaixo, deixe marcado **Commit directly to the main branch**.
10. Clique no botão verde **Commit changes**.
11. Espere 3 minutos.

Não apague nada no GitHub. O `index.html` antigo é substituído sozinho.
O arquivo `CNAME` nunca deve ser apagado.

## Como conferir

1. Abra www.poesia.art.br
2. Aperte **Ctrl + Shift + R** (no Mac: **Cmd + Shift + R**) para limpar a memória do navegador.
3. A abertura deve ser amarela, com um folheto pendurado num cordão.
4. Vá até "Vinte folhetos no cordão" e toque num folheto. Ele deve abrir para leitura.
5. Teste também no celular.

## Se precisar voltar ao site antigo

No GitHub, abra o histórico do repositório (link **Commits**). O site antigo continua salvo lá.
